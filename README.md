# sitectl-isle

A [sitectl](https://github.com/libops/sitectl) plugin for Islandora (ISLE) utilities and migration tools.

ISLE contexts include the `drupal`, `mariadb`, `solr`, and `traefik` plugins. The Traefik plugin owns
the Islandora edge components `isle-tls`, `isle-tls-override`, and `bot-mitigation`.

The docs are available at [https://sitectl.libops.io/plugins/isle](https://sitectl.libops.io/plugins/isle)
