# sitectl-isle

A [sitectl](https://github.com/libops/sitectl) plugin for Islandora (ISLE) utilities and migration tools.

## Commands

- `sitectl isle build`
- `sitectl isle init`
- `sitectl isle up`
- `sitectl isle down`
- `sitectl isle status`
- `sitectl isle logs [SERVICE...]`
- `sitectl isle rollout`
- `sitectl isle cache mirador`
- `sitectl isle migrate merge-compose-profiles`
- `sitectl isle sync fcrepo`
- `sitectl isle validate`

The docs are available at [https://sitectl.libops.io](https://sitectl.libops.io)
